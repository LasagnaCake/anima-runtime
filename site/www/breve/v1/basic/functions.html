Functions

Functions are one way of creating reusable code in Breve. They are declared as follows:

<name> :: (<arg>[, ...]) -> <type>

And can be followed by => and an expression, { ... } for a code block, or nothing, for forward declarations. For each part:

<name> is the function's name, and follows the same rule as the variable's name. Required.

<arg> is a function argument. These are declared like variables. If more than one, each argument must be separated by a comma. If an argument has a default value, that argument must be placed after all non-defaulted arguments. Optional.

<type> is the function's return type. Optional for non-forward declarations, defaults to auto-deducing the type.

Thusly, a function can be declared like the following:

// Declaring the function here, code comes later
doNothing :: () -> void

// Declaring a single-line function
square :: ( num : float32 ) => (copy num) * num

// Declaring a full-body function
factorial :: ( num : uint64 ) -> uint64 {
     out := 0
     repeat i : uint64 -> num
          out += (copy i) + 1
     return out
}

And many other possible ways.

External Functions

External functions are your way of calling cross-language code. They come in two types: Native Functions and Shared Functions.

Native Functions are one way of calling cross-language code. Native functions execute code that is defined by the ART implementation.

Declared via the @Native( name = "<native-name>" ) attribute, followed by how one would forward declare a function.

Shared Functions, much like native functions, are also for calling cross-language code. Unlike their siblings, however, shared functions execute code defined in an Anima-compatible shared library.

Declared via the @Shared( lib = <dynlib-path>, name = "<fn-name>" ) attribute, followed by how one would forward declare a function.
