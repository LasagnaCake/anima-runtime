Loops

Another building block of a decent amount of programming languages.

Breve currently contains four types of loops:

do loops: Repeats the expression indefinitely. Written in the form of do <expr>.

do ... while loops: Executes the expression, then repeatedly executes it again, while the given condition is true. Written in the form of do <expr> while <cond>.

while loops: Executes the expression repeatedly while the given condition is true. Written in the form of while <cond> <expr>.

repeat loops: Executes the expression repeatedly while the given condition is true. Can be written as:

  • repeat <count> <expr>, when an iterator variable is not needed. Count must be an integer.
  • repeat <var-decl> => <count> <expr>, when an iterator variable is required. Count must be an integer.

Note

For repeat loops, the iterator variable will start at the given count, and count down until zero is reached!

To use it as a forward index, make sure to subtract count from it.
