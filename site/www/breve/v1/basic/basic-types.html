Basic Types

Breve's standard library possesses a few types that map directly to Anima's underlying basic types:

Type Description Default Value Range
void Empty. Different from null, as it indicates that the source itself does not exist whatsoever. Cannot be used as a value directly. void void
null Null value. Indicates that the value does not exist All nullable types ( those prefixed with ? or maybe ) can accept it as a value. Cannot be used as a type directly. null null
bool Boolean value. false true or false
int8 Signed 8-bit integer. 0 -128 to 127, inclusive.
int16 Signed 16-bit integer. 0 -32,768 to 32,767, inclusive.
int32 Signed 32-bit integer. 0 -2,147,483,648 to 2,147,483,647, inclusive.
int64 Signed 64-bit integer. 0 -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807, inclusive.
uint8 Unsigned 8-bit integer. 0 0 to 255, inclusive.
uint16 Unsigned 16-bit integer. 0 0 to 65,535, inclusive.
uint32 Unsigned 32-bit integer. 0 0 to 4,294,967,295, inclusive.
uint64 Unsigned 64-bit integer. 0 0 to 18,446,744,073,709,551,615, inclusive.
float32 32-bit (single-precision) floating-point number. 0.0 ±1.7 × 10±38 , inclusive.
float64 64-bit (double-precision) floating-point number. 0.0 ±1.7 × 10±308 , inclusive.
float128 128-bit (extended-precision) floating-point number. 0.0 ±1.1897 × 10±4932 , inclusive.
char UTF-8 text character. Effectively an unicode codepoint. Same as a 32-bit unsigned integer. Same as a 32-bit unsigned integer.
string UTF-8 string. Stores each character individually as an unicode codepoint. Empty string (""). 18,446,744,073,709,551,615 characters.
bytes Binary data. No bytes. 18,446,744,073,709,551,615 bytes.
vector Four-component (X, Y, Z and W) vector of 32-bit floating point values. A vector with all components set to 0. Same as float for each component.
matrix 4x4 square matrix of 32-bit floating point values. A matrix set to its identity. Same as float for each cell.

All types in Breve are checked at compile-time for type safety. Numeric types are automatically converted between each other on any operation.

Variables are automatically initialized to their default values.

The any Type

The any type is a special type that indicates that the reciever can accept the value of (almost) any other type . All basic types (except void, null and type) derive from it.

While it can receive any value, only any types can assign to other any types without casting.

The type Type

The type type is what is considered a metatype, since it holds a type, instead of a conventional value.

Due to its nature, it can only accept other types as value, and cannot be casted to and from any.

Casting

Casting allows the programmer to convert a value of a given type to another. it is done with the as operator.

// Casts the float as an int (= truncates to 2)
var : int = (2.08 as int)

Both the source and destination types are checked if they are compatible. any is automatically assumed to be castable.

Caution!

Be careful when casting from any to any type! Make sure you check at runtime that the destination type is the expected type!
