Special Types

Breve possesses a set of special types, those being:

  • Arrays
  • Nullable (option) types

Arrays

Array types are used for storing sequential data of a given type. Breve arrays are dynamic, meaning that you can add and remove elements from them.

To declare an array type, use [<type>].

To create an array, several methods can be used:

If types are guaranteed to be the same, thus inferrable:
[<expr>[, ...]]

If types are compatible with one another:
new [<type>] {<expr>[, ...]}

If you know the minimum size:
new <type>[<size>] {<expr>[, ...]}

Examples:

[1, 2, 3]

new [int] {1, 2, 3}

new float[6] {1, 2, 3}

To create an empty array, simply use the new expression, while ommiting the curly bractets.

Nullable (Optional) Types

Nullable types are types that can accept null as a possible value, alongside its own type. These types are useful for functions that has operations that may fail.

To declare a nullable type, use ?<type> or maybe <type>.
