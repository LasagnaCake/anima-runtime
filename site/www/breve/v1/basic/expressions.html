Expressions

Expressions are the building blocks of your code. These can be the following:

Unary Expressions: Self-explanatory, only has one argument.

Binary Expressions: Comprised of a left-hand side and a right-hand side.

Ternary Expressions: Has three arguments.

Variadic Expressions: Has two or more arguments.

Block Expressions: Surrounded in curly brackets, contains zero or more expressions.

Declarations: Comes in many shapes and sizes, those being:

  • Variable declarations
  • Function declarations
  • Namespace declarations
  • Structure declarations
  • Enumeration declarations
  • Type extensions declarations
  • Property declarations
  • Trait declarations
