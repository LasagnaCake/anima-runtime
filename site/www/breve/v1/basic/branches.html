Branches

One of the main building blocks of every programming language.

Breve contains four types of branches, divided in two types and two categories, those being:

if branches: Your standard programming language branch, which executes code when the given condition is true. May optionally have an else clause.

unless branches: The opposite of if branches, that only execute code when the given condition is false. May also optionally have an else clause.

when branches: Instead of a ternary operator that most programming languages have, breve uses an inline if-else, in the form of <on-true> when <condition> else <on-false> . The condition is checked first, then the appropriate path is taken. Both paths must exist.

except branches: The inline version of unless branches. Like its sibling, Both paths must exist.

Note

You are not required to surround the condition with parens.

Caution!

For every single branch type, every code path must result in a value of the same data type!

// Conventional if-else branches can be used
// In place of inline if-elses, if preferred

isEven1 :: ( num : uint64 ) =>
     if num % 2
         IO.writeLine ( "Is odd!" )
     else
         IO.writeLine ( "Is even!" )

isEven2 :: ( num : uint64 ) =>
     IO.writeLine ( "Is odd!" when num % 2 else "Is even!" )

likely and unlikely

By default, the compiler tries to assume the likelihood a given branch of code is taken, to optimize for a specific code path.

If a given code path is known to be more likely to happen than the other, then this behaviour can be overwritten with the likely and unlikely keywords.

Inserting these before the condition flags to the compiler the appropriate course of action to take for the given branch.
