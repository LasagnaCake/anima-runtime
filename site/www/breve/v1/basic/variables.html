Variables

Variables are a way to store data in Breve. These come in many different flavours:

Local variables: These are stored in the scope-local stack, and can only be utilized in the scope they are declared in.

Global variables: These are stored in the global space. While their declarations are scoped, their value can be accessed from any scope, by using the same address name.
Declared with the @Global("<addr-name>") attribute.

Static variables: These are stored in a hidden section of the global space.
Declared with the @Static attribute.

External variables: These variables are stored in an implementation-defined place. This behaviour varies from one ART implementation to another, as it is intended to be one way for cross-language communication. This variable location can only be read from. Declared with the @Out("<addr-name>") attribute.

Declarations

Variables are declared as such:

<name> : <type> = <value>

Where:

<name> is the variable's name. Follows the same rules as variables in most conventional languages.

<type> is the variable's type. These can be basic types, or classes. Optional if <value> exists.

<value> is the variable's value. Optional if <type> exists.

Thusly, variables can be declared as:

var1 : int64

var2 := 0.2f

var3 : uint16 = 5

And many other ways.
